# Hopeless Tides

Version 0.17.3. By **David Mulkey (Hopeless Engineering)**.

A Minecraft Forge 1.20.1 mod. It gives water physical waves that change with the weather, with splashes, foam and its own water shader.

## What is here

- `src/` - the mod source (Java, GLSL) and its resources.
- `tools/` - tests and analysis tools.
- `research/` - the research the values come from.

## Build

Build with the javac build chain in [HopelessMCTool](https://github.com/ToothlessOneX/HopelessMCTool) (`mcbuild.sh`), or adapt `build.sh` (it has the paths of the cloud workspace where it was made). Tides compiles against Embeddium: set `EXTRA_CP=<embeddium jar>`.
